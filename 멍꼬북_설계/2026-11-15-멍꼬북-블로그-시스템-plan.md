# 멍꼬북 블로그 반자동 작성 시스템 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task (사용자 지정 방식). Steps use checkbox (`- [ ]`) syntax for tracking.
> 실행 장소: 사용자 PC(Windows)의 Claude Code 데스크톱 앱, 작업 폴더 = ROOT. 사용자는 비개발자 — 설치·명령은 복붙용 한 줄씩, 쉬운 말, 한국어. 각 Task 끝마다 superpowers:verification-before-completion 기준으로 **실제 실행 결과를 보여준다.**

**Goal:** 주제 폴더(사진·영상·memo) + 한 줄 명령으로 멍꼬북 문체 초안(md/html/json)을 만들고 검사한 뒤, 사용자의 크롬에서 네이버 해당 게시판에 **임시저장**까지 하는 `/멍꼬북` 스킬.

**Architecture:** 결정적인 일(경로 해석, 사진 변환, 렌더, 검사, 상태 기록)은 `_system\scripts\mkb` Python 패키지(CLI: `python -m mkb …`)가 하고, 판단(사진 배치, 글쓰기, 사실 확인, 브라우저 조작)은 Claude가 스킬 지시에 따라 한다. `draft.json`이 단일 원천이며 md/html은 여기서 생성한다.

**Tech Stack:** Python 3.12, Pillow, pillow-heif, pytest, Git(로컬 기록용), Claude in Chrome 확장.

**Spec:** `_system\docs\2026-11-15-멍꼬북-블로그-시스템-design.md` (+ 원 프롬프트 `원프롬프트_멍꼬북_ClaudeCode_시작프롬프트.md`). 설계 문서가 우선.

## Global Constraints

- ROOT = `J:\3. 블로그\멍꼬북 블로그_요리, 맛집, 장소, 도서, 영화리뷰, 디지털드로잉, 일상\` — `_system\config.json`의 `root`에만 저장, 코드에 하드코딩 금지. 경로는 `pathlib`, 파일 입출력은 `encoding="utf-8"`, 실행은 `PYTHONUTF8=1`.
- 기존 폴더·원본 사진/영상은 **읽기만**: 이동·이름변경·수정·삭제 금지. 시스템이 쓰는 곳은 `_system\`, 주제 폴더의 `memo.txt`(새로 만들 때만), `_output\` 뿐.
- 발행 금지, 임시저장만 / 명령받은 글 1개만 / 비밀번호 저장 금지 / 로그인·캡차·2단계 인증 시 멈춤.
- 첫 임시저장은 **소비기록 > 외쿡 맛집(비공개)**.
- '일상기록 > 소소한 하루일기'는 절대 사용하지 않음. 일기 = '일상기록 > 소소한 하루'.
- 본문 15pt, 강조 배경 `#FFF5B1`, 강조 글 전체 3~5회·문단당 1회, 사진 최대 20장, 영상 경고 300MB, 검사 재시도 최대 3회, 긴 변 최대 2000px.
- 사진 placeholder 문구("사진 설명을 입력하세요" 등) 절대 금지. memo에 없는 수치 지어내기 금지 → `[○○ 확인 필요]`.
- 테스트는 `_system\scripts\tests\`의 pytest, 실행: `cd "_system\scripts"` 후 `python -m pytest -q`.
